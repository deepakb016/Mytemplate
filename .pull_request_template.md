---
title: "Pin pytest to <9.0.0 to resolve dependency conflict with pytest-playwright"
body: |
  CI was failing when installing test dependencies because pytest-playwright requires pytest < 9.0.0 while pytest 9.x could be selected by the resolver.
  
  This PR pins pytest to a range compatible with pytest-playwright so pip can resolve dependencies successfully in CI.
  
  Changes:
  - requirements.txt: pytest==8.2.0 → pytest>=6.2.4,<9.0.0
  
  Testing steps:
  - pip install -r requirements.txt
  - pytest

labels: |
  - dependencies
